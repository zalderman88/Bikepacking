# Bikepacking Route Planner

Plan a 6 to 12 month bikepacking trip through Mexico, Central and South America around the dry seasons. Pick a route and a start date and every day of the ride is placed on a season map, scored against the weather where you will be, and split into legs you can ride on dirt, on the main road, or skip by bus.

**Open it:** https://zalderman88.github.io/Bikepacking/

## Put it on an Android phone

1. Open the link above in Chrome.
2. Tap the ⋮ menu, then **Add to Home screen** (or **Install app**).
3. Open it from the home screen icon from now on. It works offline once it has loaded one time, and your plan is kept between visits.

## Share a plan

Tap **Share plan** on the trip card. The link you send opens the planner with your route, start date, pace, breaks and leg choices already set.

## What is in here

| File | What it is |
| --- | --- |
| `index.html` | The page |
| `app.js` | Route engine and interface |
| `geo.js` | Country outlines for the map |
| `sw.js` | Offline support |
| `manifest.webmanifest`, `icons/` | Home screen app details |
| `vendor/d3.min.js`, `fonts/` | d3 7.9.0 and the Archivo and Atkinson Hyperlegible fonts, kept local so it works offline |
| `hero.webp`, `og.jpg` | Header artwork made in Canva, and the image shown when the link is shared |

Sources for routes, seasons and safety notes are listed at the bottom of the page.
